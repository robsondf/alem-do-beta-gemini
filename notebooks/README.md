# Notebooks congelados

Foram mantidos os notebooks temporal, setorial/de risco, C, D e E já presentes no GitHub. D integra as dependências congeladas de E. Não foram copiadas as execuções ou os notebooks do Drive.

Esses arquivos preservam os lançadores originais, incluindo suas URLs e versões. Sua presença documenta o procedimento; não garante execução sem credenciais, caches ou acesso ao repositório de origem. Consulte `../docs/REPRODUCTION.md` para execução a partir dos scripts desta cópia.

Os notebooks antigos de investigação e suas execuções versionadas permanecem na origem. A seleção completa está em `../provenance/selection.json`.
