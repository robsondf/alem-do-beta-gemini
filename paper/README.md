# Manuscrito principal

Leia `main.pdf`. O arquivo principal para compilação é `main.tex`, que inclui `artigo_revisado.tex` e utiliza `references_artigo.bib`.

Os fontes científicos e o PDF são cópias exatas do commit de origem indicado em `../provenance/selection.json`. Foram retidos somente os estilos, figuras e tabelas utilizados pelo principal. O dossiê e as versões anteriores continuam no repositório de origem.

O artigo tem 20 páginas, 35 referências citadas, oito figuras e seis ambientes de tabela. Três tabelas usam arquivos externos e as demais estão no corpo LaTeX. Para Overleaf, use o conteúdo deste diretório, `main.tex` como principal e pdfLaTeX/BibTeX. Veja `../docs/REPRODUCTION.md`.
