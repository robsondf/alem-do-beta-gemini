# Resultados conferidos

Foi retido um espelho de cada etapa Colab final já versionada no GitHub, sem duplicatas de preparação local e sem imagens repetidas. Os gráficos usados no artigo estão em `../paper/figures/lab02/`.

Arquivos `.csv.gz` são tabelas compactadas. Os manifestos preservados descrevem os exports integrais originais, incluindo arquivos que permanecem externos. O espelho leve não deve ser apresentado como export integral nem usado isoladamente em verificadores que exigem arrays NPZ.

As tabelas não foram recalculadas, arredondadas ou selecionadas pelo sinal dos resultados. Consulte o artigo para estimandos, famílias de testes, incerteza e limitações.
