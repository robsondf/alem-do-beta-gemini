# Protocolos e evidências

Este diretório mantém protocolos, manifestos, recibos e pequenas dependências documentais que já estavam no GitHub. A subpasta de fontes primárias E foi preservada porque seus arquivos integram os hashes do runtime congelado; não representa transferência de arquivos do Drive.

As matrizes diárias completas e os exports integrais X/B/D/E não integram esta cópia. Seus hashes e referências externas estão nos manifestos originais. Eles são necessários para reproduzir integralmente os experimentos; os resultados compactos no GitHub não os substituem.

Não altere protocolos ou recibos históricos para acomodar uma nova execução. Use pastas novas e registre a proveniência separadamente. Nenhum documento de terceiros foi relicenciado.
